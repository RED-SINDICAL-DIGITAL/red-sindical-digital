# ★ UADAV STREAM V7.4

- D1 `DB` treated as central source for public artists, radios and cartelera when the binding exists; KV remains compatible/fallback.
- Invidious is permanent in the search/discovery pipeline: global search, artist prospecting and channel resolution.
- Added multiple Invidious instances and Admin health diagnostics.
- Artist prospecting combines YouTube + Invidious and deduplicates results before saving.
- Public profile navigation uses **Mi perfil**; `mi-uadavstream.html` remains a compatibility alias.
- Cartelera reads from D1 when available and falls back to KV.
- Make removed from active architecture; D1 + Cron handle notification retries, with Google Apps Script/Gmail as optional email delivery.
- Cloudflare Queue remains optional.
