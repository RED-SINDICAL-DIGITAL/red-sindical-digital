Manual operativo

Guía simple para trabajar sin tocar código. La regla general es: el sistema automatiza la carga, clasificación y vencimientos; administración interviene en conflictos, destacados pagos, afiliación, reclamos o información incorrecta.

Rutina diaria recomendada

  1. Entrar a Resumen y mirar pendientes.
  2. Resolver reclamos, destacados pagos, posibles duplicados y denuncias.
  3. Importar planillas nuevas que hayan llegado de seccionales/productoras.
  4. Usar Enriquecer incompletos en Artistas.
  5. Revisar campañas próximas a vencer.
  6. Hacer backup periódico.

Home y secciones

El Home funciona con filas configurables. No hace falta editar HTML para cambiar el contenido editorial.

ModoUso
ManualElegís exactamente cada contenido.
AutomáticoEl sistema completa por reglas/categorías.
HíbridoFijás algunos contenidos y el sistema completa el resto.

Recomendación: usar Híbrido para la mayoría de las filas. Mantiene control editorial sin obligarte a llenar todo a mano.

Artistas

  1. Crear manualmente, importar Excel o buscar prospectos.
  2. Si hay canal, usar Enriquecer: Invidious primero y YouTube oficial solo como fallback.
  3. Si un perfil viejo tiene nombre de videoclip, usar Reparar identidad.
  4. Revisar visibilidad, rubro y afiliación.
  5. El artista puede reclamar su perfil; administración conserva el control editorial.

Importar cientos de URLs/metadatos no significa alojar videos. D1 guarda texto y referencias. Lo pesado sigue en YouTube, Spotify, Vimeo, etc.

Artista afiliado: apoyo, comunidad y Press Kit

Estos beneficios se habilitan para artistas afiliados verificados. La cuota sindical es independiente: los aportes del público no reemplazan ni se mezclan con la afiliación.

  1. Activar Apoyo público en Artistas o desde el espacio privado.
  2. Cargar enlaces externos autorizados: Ko-fi, Cafecito, Mercado Pago, PayPal, tienda o fan club.
  3. Habilitar Chat de audiencia si el artista desea comunidad pública moderable.
  4. Habilitar Press Kit para generar una ficha profesional imprimible/PDF.
  5. Habilitar Marketplace para recibir consultas de contratación.

UADAV STREAM no procesa por sí sola el dinero de estos enlaces externos. El artista elige y administra su medio de apoyo.

Productoras

Registrar nombre, contacto, ciudad y si existe convenio. Para una productora con muchos artistas, usar la plantilla Productora y cargar todo de una vez. Los perfiles siguen perteneciendo al catálogo central de UADAV STREAM.

Radios

  1. Mínimo: Nombre + URL del stream.
  2. Recomendado: logo, portada y metadata.
  3. Metadata habilita “Ahora suena”, historial y carátulas.
  4. Pedidos musicales se gestionan separados del chat.
  5. Pauta / destacada / Radio Partner son opciones comerciales, no cambian la señal.

La radio puede publicarse gratuitamente. El destaque se vende como visibilidad adicional.

Eventos y Cartelera

Los eventos normales se publican automáticamente. Si el organizador pide destaque, el evento sigue en Agenda pero el espacio premium queda pendiente de revisión/pago.

  1. Cargar poster horizontal/vertical, fechas, lugar y ticketera.
  2. Publicar.
  3. Si compra destaque: crear/activar campaña con inicio y fin.
  4. El sistema quita el destaque al vencer.

Venta sugerida: Slider principal, Destacado de Cartelera, Hero Home y combos. Los precios se definen desde administración, no están hardcodeados.

UADAV Tickets

V8.5 incorpora la base de ticketing propio sin activar todavía cobro automático.

  1. En Eventos elegir UADAV Tickets como modo de entradas.
  2. Definir capacidad/cupo si corresponde.
  3. El público puede registrar una solicitud de entradas desde la ficha del evento.
  4. Admin gestiona las solicitudes desde Solicitudes y comunidad.
  5. La integración de pagos/QR se agrega en una etapa posterior, separada de la cuota sindical.

Películas y Series

Se guarda metadata + enlaces/embeds autorizados. Una serie se organiza como Título → Temporadas → Episodios. No se alojan archivos pesados dentro de D1.

Contenido, Playlists y Podcast

La biblioteca universal acepta referencias de YouTube, Spotify, OK.ru, Drive, Vimeo, SoundCloud, Twitch, Kick y URLs propias cuando la plataforma permite enlazar o embeber.

No hace falta que una seccional cargue contenido técnico. Puede enviar solamente datos del artista; UADAV STREAM lo enriquece después.

Shorts

La experiencia vertical usa scroll-snap tipo TikTok/Reels. Primero muestra Shorts cargados/controlados y puede descubrir material externo bajo nuestras reglas de búsqueda.

Bolsa de trabajo

Productoras/particulares pueden publicar oportunidades. Administración solo interviene si hay información incorrecta. Las reglas de postulación de artistas se mantienen separadas.

Importar / Exportar

Importación simple

Seccionales y productoras pueden enviar: Nombre, Rubro, Ciudad, Provincia, País, Email, WhatsApp y Canal/URL opcional.

Importación avanzada

Admin puede importar Artistas, Productoras, Radios, Eventos, Bolsa, Contenido, Playlists, Podcast, Películas/Series, Temporadas, Episodios, Colecciones y Secciones. Elegir Todo / detectar hojas procesa cada hoja reconocida de la plantilla completa.

Exportación

Perfiles completos XLSX genera hojas separadas para Perfiles, Contenido, Playlists, Podcast, Eventos, Fuentes y Calidad.

D1, KV e IA

D1 registros estructurados. KV configuración/cache/fallback. Gemini ayuda a clasificar, limpiar datos, detectar faltantes y SEO.

La IA no debe aprobar afiliaciones, pagos, sanciones ni borrar datos por sí sola.

Backup y auditoría

Antes de importaciones grandes o cambios estructurales: exportar Backup D1 JSON. Usar Auditoría para rastrear acciones y cambios.

CCT 340/75 · Asistente sindical

Admin → Trabajo → CCT 340/75 permite clasificar especialidad, revisar requisitos contractuales, funciones, aporte sindical y circuitos SADAIC/AADI. Las escalas vigentes deben ser cargadas por UADAV: los valores impresos en el convenio de 1975 son históricos.

  1. Cargá las escalas vigentes en Admin.
  2. Ingresá el caso del show.
  3. Revisá alertas, aporte estimado y documentación faltante.
  4. Guardá el caso para fiscalización/seguimiento.
  5. El afiliado puede usar una versión orientativa desde Mi espacio → Derechos.
