# ★ UADAV STREAM V7.4.1 — Correcciones críticas

## Admin
- Corregida la persistencia de la clave de administrador: después de validar `admin_check`, la clave se conserva durante la sesión y se reutiliza en las llamadas privadas.
- Eliminado el borrado automático de la clave al cargar la página.
- Corregido `restoreAdminKey()` para restaurar la sesión en lugar de vaciarla.
- Las lecturas privadas del Admin usan el wrapper autenticado y ya no envían GET sin `Authorization`.
- El sidebar del Admin deja de flotar sobre el contenido: en escritorio ocupa una columna real; en móvil pasa a navegación superior/horizontal.
- El panel de sesión / salir queda contenido dentro del sidebar.

## Cuota de YouTube
- **Invidious es ahora la fuente principal para descubrimiento.**
- La API oficial de YouTube queda desactivada por defecto.
- Solo se utiliza si el administrador la habilita explícitamente desde Admin y existe `YOUTUBE_API_KEY`.
- Esto aplica a prospección, búsqueda global, trending y resolución de canales.
- Se agregó control administrativo `admin/youtube-provider`.
- Se agregó resolución de canal mediante `GET /api/v1/channels/:id` de Invidious.
