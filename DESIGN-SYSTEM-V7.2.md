# ★ UADAV STREAM — Design System V7.2

## Dirección
- Plataforma audiovisual: lenguaje Netflix + YouTube Music + Teatrix.
- Radio/música: player y catálogo con lenguaje Spotify/YouTube Music.
- Admin: dashboard de aplicación con sidebar fijo, tarjetas, tablas y estados.
- Identidad: estrella + UADAV STREAM, configurable desde Admin.

## Base visual
- Fondo: grafito/negro.
- Acento: cian.
- Acento secundario: violeta.
- Tipografía: Inter/Outfit/system.
- Bordes suaves, superficies profundas y contraste alto.

## Componentes
- Video cards 16:9.
- Artist cards 1:1.
- Radio cards con logo + ahora suena.
- Event cards con fecha visible.
- Mini-player persistente.
- Player expandido.
- Hero cinematográfico.
- Mobile nav inferior.
- Admin sidebar + dashboard cards.

## Regla de producto
La identidad es compartida, pero cada superficie tiene su propio lenguaje: plataforma pública, música/radio y centro de control.
